
#### Emotion-Aware Smart Classroom (SIH '25) 🎓🤖

An edge-AI embedded classroom monitoring system built on **Raspberry Pi** for Smart India Hackathon '25 to analyze student engagement and facial expressions in real time. 

#### Key Highlights

* **Edge Computer Vision:** Deployed lightweight facial expression recognition models on **Raspberry Pi** using **OpenCV** and **TensorFlow Lite** for low-latency on-device inference.
* **IoT Dashboard & Alerts:** Connected real-time engagement telemetry to a **Node-RED** dashboard for live classroom feedback and analytics.

#### Tech Stack

* **Hardware:** Raspberry Pi, Camera Module
* **Languages & Libraries:** Python, OpenCV, TensorFlow Lite
* **IoT & Visualization:** Node-RED
